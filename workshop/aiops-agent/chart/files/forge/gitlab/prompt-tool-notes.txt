\n- `gitlab` MCP: `create_merge_request` / `create_branch` only. The gitlab write path is create_or_update_file, which UPSERTS (create if the file is absent, update if it already exists) — use it to edit an EXISTING overlay; if a write is rejected with commit_id Required, first READ the file on your branch to get its last-commit id and retry as an update; and NEVER call a create action on a file that already exists (GitLab returns 400 Bad Request) — read the file first: found means update, not-found means create. Do not thrash between create and update.
