\n- `argocd-status` MCP: `argocd_unhealthy_applications(cluster?, addon?)` reads EVERY Argo CD Application on the hub and returns `total`, `unhealthy`, counts per state and one compact row per app that is not Synced and Healthy. ALWAYS call it first for any question about Argo CD Application health or sync (which apps are not Synced/Healthy, what is broken in the fleet, is cluster X or addon Y green), instead of listing and reading Applications one by one with eks-read. Answer with `<unhealthy> of <total>` Applications; an empty list with `total` > 0 means every Application is Synced and Healthy. Use eks-read only to dig into one app or its resources afterwards. If the tool is unavailable or errors, fall back to the per-Application read rule above.
